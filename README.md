# 職人への道！三枚おろしシミュレーター

ブラウザで遊べる、魚の三枚おろしシミュレーションゲームです（React + SVG の単一 HTML、ビルド不要）。

- `sanmai-oroshi.html` … ゲーム本体（2D）。React・htm は CDN から読み込みます。
- 魚：アジ（★1）・サバ（★2：身がやわらかく割れやすい）・タイ（★3：うろこが硬く、背ビレに棘）
- 操作：道具箱（手・出刃包丁・うろこ取り・濡れ布巾・流水・ペーパー・塩）から道具を持ち替え、魚に直接使う。分身の手で魚を押さえる
- 包丁は引いたとおりに入る。狙いのない線は切り傷として身を傷め、順序違いは身割れ・汚れなどの結果になる
- 失敗：魚を胴の途中で切断する／切り傷で身の傷み度が100%に達する／押さえている手を切る
- 工程：魚の確認 → 下処理 → 三枚おろし → 仕上がり確認（100点満点で採点）
- 難易度：練習・通常・職人
- 魚種データ（形状パラメータ・ヒレ・工程・解説）は `FISH_SPECS` にまとめてあり、同じ構造で魚を追加できます。

## テスト

`tests/play-2d.js` は Playwright で主要な操作の流れを自動で通すテストです（CDN の読み込みはローカルファイルに差し替え）。

```
LIBS_DIR=<react.production.min.js / react-dom.production.min.js / htm.umd.js を置いたフォルダ> \
FISH=aji MODE=practice SCEN=full node tests/play-2d.js
```

`SCEN` は `full`（通し）・`sever`（切断で失敗）・`damage`（切り傷で失敗）・`handcut`（手を切って失敗）・`order`（順序違い）・`spike`（タイの棘）。
