# 職人への道！三枚おろしシミュレーター

ブラウザで遊べる、アジの三枚おろしシミュレーションゲームです（React + SVG の単一 HTML）。

- `sanmai-oroshi.html` … ゲーム本体。React・htm は CDN から読み込みます。
- 操作：道具箱（手・出刃包丁・うろこ取り・濡れ布巾・流水・ペーパー・塩）から道具を持ち替え、魚に直接使う。分身の手で魚を押さえ、手が刃の通り道にあると切れない
- 工程：魚の確認 → 下処理（うろこ・ぜいご・頭・内臓など）→ 三枚おろし（ドラッグで切断線を引く）→ 仕上がり確認（100点満点で採点）
- 難易度：練習・通常・職人
- 魚種データ（形状パラメータ・工程・切断線）は `FISH_LIST` にまとめてあり、サバ・タイを同じ構造で追加できます。
