# 因果の検証結果（S1）

因果プローブの再現方法：

```bash
cd dotnet && dotnet run -c Release --project WorldSim.Cli -- --days 60 --probe
```

- 手順：種1の町を60日進めて保存し、そこから介入を1つ加えて90日進め、最後の14日を平均して基準と比べます。
- 乱数の扱い：乱数を3通り（保存時の状態＋2つの別の種）に変えて同じ比較を行い、平均します。
- 「?」の意味：結果の表で「?」が付いたものは、乱数によって向きが変わる（偶然に左右される）結果です。
- 自動テスト：`CausalProbeTests` が、効果の向きと「偶然ではないこと」を検査します。

記号：
- **［確認］** 実行・計測した事実
- **［コード確認］** コードを読んで確かめた事実
- **［推測］** 判断・見込み

## 監査で挙げた項目の結論

### 1. 火力発電所が汚染を出していなかった → **不具合として修正**［確認］

**原因**：生産システム（6時）が、全企業の「今日の生産量」を0に戻していました。発電所も対象でした。そのため、電力システム（4時）が記録した発電量が消え、汚染システム（13時）は常に0を読んでいました。

**修正**：生産システムは、レシピを持たない発電所の記録を消さないようにしました。

**テスト**：`PowerPlantsPolluteInProportionToOutputAndScrubbersHelp`
- 稼働中の発電所は汚染する。
- 排煙装置で減る。
- 無人の発電所は汚染しない。
- 修正前のコードでは失敗することを確認済み。

**影響**：10年連続実行で人口は約880〜920人で安定。1日あたりの計算時間は3.8msで変化なし。

### 2. 電気料金100円で食品生産が −100% → **因果として正しい。ただし設計上の不足がある**［確認］

**経路**：
1. 食品工場は1日1,500kWhを使う。
2. 料金が上がると、1日あたり15万円の追加費用になる。
3. 食品工場は、基準の状態ですでに赤字（平均 −1.9万円／日）。
4. 3社すべてが14日以上の資金不足で倒産する。
5. 食品は輸入に置き換わる（輸入 +42%）。
6. 失業が増える（+22%）。

**設計上の不足**：企業が費用の上昇を価格に転嫁できません。価格は市場全体の需給で1日±2%しか動かず、上限も基準の1.6倍です。現実なら値上げで一部を吸収するところが、崖のような倒産になります。→ S3（企業の値付け）で扱います。

### 3. 年金0で電力供給 −29% → **偶然（因果ではない）**［確認］

**原因**：政策を変えると乱数の使われ方がずれます。その結果、町に1つしかない発電所が、測定期間中に2回故障しました（各3日の停電）。

**対策**：プローブを3通りの乱数で行うようにしました。この結果には「?」が付き、偶然と分かるようになりました。テスト `ChanceEventsAreNotMistakenForEffects` で検査しています。

**因果として残った年金0の効果**（3通りとも同じ向き）：
- 満足度 −3.1%
- 小売 −3.6%
- 企業利益 −47%
- 市の資金 +8%

**副次的な発見**：発電所が1つだけなので、故障で町全体が止まります（単一障害点）。現実的ですが、プレイヤーに見えるように説明（S1-4）で示します。

### 4. 住宅を建てても人口が増えない → **因果として正しい（仕様どおり）**［コード確認・確認］

**原因**：移入の式は「求人数×0.15 ＋ 空き家×…×max(0, 1 − 8×失業率)」です。
- 失業率が12.5%以上だと、空き家は人を呼びません。
- 基準の町は失業率が約20%で、求人もほぼ0です。

「人は仕事を追って移住する」という意図どおりの動きです。町の近くの道路沿いに建てても同じ結果で（プローブ「町の近くに集合住宅6棟」）、場所や道路の問題ではないことを確認しました。

### 5. 地震で失業が −30% → **因果として説明できた。ただし設計上の課題がある**［確認］

3通りの乱数すべてで同じ向き（−25.6%）でした。原因の記録（S1-3）と分岐比較（S1-4）で、地震の分岐と基準の分岐の差を分解しました。

| 時点 | 失業率（地震／基準） | 差の主な原因 |
|---|---|---|
| 10日後 | 23.5% ／ 16.1% | 通勤が長すぎて離職 +63.7pt、就職 −63.9pt、求人を求めて転入 +7.1pt（転入77人） |
| 90日後 | 13.9% ／ 17.3% | 就職 −87.9pt、通勤で離職 +82.0pt、不満による転出 −6.6pt（55人）、倒産 +4.0pt |

**経路**：
1. 道路の損傷で通勤時間が上限を超え、多数が一度に離職する。
2. 大量の欠員が生まれ、求人を求めて人が転入する（貯蓄を持ち込むので買い物が増える）。
3. 欠員が埋まる。
4. 不満を持つ住民（失業者を含む）が転出し、求職者が減る。

結果として、90日後の失業率は基準より低くなります。
- 市の資金の差 −1.65億円は、ほぼすべて修理・復旧費です。
- 修理・復旧費は市外へ支払われ、地元の雇用になりません。

**設計上の課題**：
- 通勤できない日が続くと即座に離職する。一時的な休業・在宅などの段階がない。→ S3（主体の判断）で扱います。
- 復旧費が地元の建設業に回らない。→ S2（建設業）で扱います。

## S2 経済の輪を閉じる（2026-10-17）

S1の「なぜ？」で見つけたお金の流出と、欠けていた因果の輪を、小さな段階ごとに閉じました。各段階で介入実験・自動テスト・10年連続実行を行っています。

| 段階 | 内容 | 確認できた因果［確認］ |
|---|---|---|
| S2-1 建設業 | 市の建設費・維持費・復旧費・防災工事、企業の設備修理を、町の建設会社が受注する（受注残は30日分まで。超えた分は市外の業者へ）。資材（鋼材・木材）は地元か輸入で調達。受注残に応じて人を雇う | 建設会社を撤去すると、人口 −1.4%・小売 −2.2%・市の資金 −1.8%（3通りの乱数すべて同じ向き）。地震の復旧費が地元の雇用になる |
| S2-2 家賃と住宅 | 市営住宅（この段階の仮定）。家賃は「標準家賃×地価（0.5〜1.5倍）」。所得の低い世帯は家賃を重く、高い世帯は立地を重く見て住まいを選ぶ。家賃が所得の30%を超えると満足度が下がり、50%を超えると安い住まいへ移る。30日滞納で退去し、払える住まいがなければ転出する | 家賃3倍で市の資金 +16%、小売 −5%、満足度 −3.7%。家計の貯蓄の目減りが止まった（以前は10年で約4分の1） |
| S2-3 健康 | 住まいと職場の大気汚染・年齢・食事で健康が下がり、休息と診療所（定員あり）で回復する。健康が死亡率（最大4倍）・労働生産性・満足度に効く | 製鉄所の隣の住宅では健康が下がり、診療所があると高く保たれる（テスト）。既定の町は汚染が低く、健康はほぼ高いまま |
| S2-4 企業向けサービス | 工業（製鉄・食品・工場）がオフィスのサービスを「任意の投入物」として買う（無いと10%効率が落ちる）。オフィスは余ったサービスを輸出できる | オフィスが人員を減らさず雇えるようになり、10年後の人口 約890→約1,080、失業率 12〜20%→7〜10% |

**S2で直した不具合**：土地の価値を保存していなかったため、読み込んだゲームが元と違う未来になった。これを修正し、テストで検出できるようにしました。

**S2後の介入実験（抜粋）**：
| 介入 | 主な結果（3通りの乱数で同じ向き） |
|---|---|
| 地震 M7.5 | 失業 +25%、人口 −5.5%、市の資金 −44%（S1時点の「失業が減る」直感に反する結果は、建設業と家賃が加わって解消） |
| 市外への道路を遮断 | 失業 +144%、輸出入 −100%、人口 −11% |
| 家賃3倍 | 市の資金 +16%、小売 −5%、満足度 −4% |
| 商店をすべて撤去 | 小売 −91%、満足度 −22%、人口 −15% |

**残る課題（S3以降）**：
- 市の資金が年に数千万円ずつ積み上がる。家賃収入を使う主体（自治体の判断）がない。
- 住宅の所有者は市のみという仮定。民間の大家・住宅会社はまだない。
- 加工業（製鉄・工場・食品）の多くが赤字のまま。生産量と価格の釣り合いの見直しが必要。
- 人口の入れ替わりが大きい。毎年 約240人が長期失業で転出し、約230人が転入する。

## S3 自律する主体（2026-10-17）

| 段階 | 内容 | 確認できたこと［確認］ |
|---|---|---|
| S3-1 価格転嫁 | 赤字の地元生産者の単位費用（前日の費用÷生産量）が価格の1.05倍を超えると、品不足・供給過剰がない限り価格が1日2%上がる（原因「費用の上昇を価格に転嫁」）。輸入価格と価格の上限が歯止めになる | 加工業（製鉄・食品・工場）が赤字続きの状態から抜けた。電気料金の値上げが価格転嫁の原因として記録される（テスト） |
| S3-2 民間投資家 | 週に1度、過去30日を見る。輸入超過（新工場1つ分の生産の半分以上）か小売の品不足が続き、既存の同業者が黒字で人手が7割以上足り、働き手がいる（失業率4%以上）とき、外部資金で企業を開業する（60日に1社まで、道路のある場所） | 店のない村に店が開業し、理由が記録される。政策で止められる。最初は「赤字で人手不足の工場」まで増やしてしまったため、「既存の同業者が順調か」の条件を加えた |
| S3-3 自治体（任意） | 月に1度、財政の余力（日数）・失業率・家賃負担・被害を見て、最大2つの政策を少しずつ変える。既定は無効。「人生体験中のみ」も選べる | 黒字の町は余力を産業補助に回し、資金は約8〜10億円で安定（無効時は10年で30億円に積み上がる）。資金不足の町は増税する（テスト） |

**主体が加わって変わった介入実験の結果**：
- 商店をすべて撤去する → 投資家が店を開き直すため、小売の減少は −91% から −16% に縮んだ（町が自分で回復する）。
- 食品工場を撤去する → 輸入で補ったあと、投資家が新しい工場を建てるため、食品生産は −100% から −66% になった。

**残る課題**：
- 判断は規則に基づくもので、学習や将来の予測はしない。
- 自治体は減税・補助・家賃・復旧予算だけを扱い、公共施設の建設はまだしない。
- 投資家は撤退（建物の売却・解体）をしない。
